# Maintaining Awesome AI

This list mixes open-source projects and hosted services. Keep each entry useful as a starting point for readers:

1. Link to the project's current official repository or documentation. Avoid old repositories that merely redirect to an archive.
2. Describe what the linked project does in one factual sentence. Distinguish a product from a cookbook, SDK, or example repository.
3. Put the entry in the section that matches its main use. If a section no longer describes its entries, rename the section and its table-of-contents link.
4. For a GitHub repository, use a stars badge for that exact repository. For a product or documentation page, use `-` in the Repos column.
5. Label an archived project explicitly if it remains valuable for historical reasons; otherwise remove it.
6. Run `python scripts/check_links.py` before proposing changes. This checks destinations, but a reachable page is not evidence that a service is still maintained or that its description is current. Check those claims against the project's own documentation.
